CourseCraft – Online Learning Platform (Frontend)

CourseCraft is an Udemy-like online learning platform frontend project.  
It is built using HTML, CSS, and Bootstrap with a focus on responsive design, clean UI, and real-world project structure.

Project Idea
CourseCraft simulates an online course platform where users can browse courses, view pricing, and interact with a modern learning-style interface similar to Udemy.

#Tech Stack
- HTML5
- CSS3
- Bootstrap 5

Features
- Responsive UI for all screen sizes
- Course cards with price and ratings
- Carousel for featured courses
- Clean navigation bar
- Login and Register pages (UI only)
- Course listing layout
- Cart-style page design
- Bootstrap grid and components
